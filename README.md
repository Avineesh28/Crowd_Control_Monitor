# Crowd Control Monitor Using Computer Vision

## Overview

The **Crowd Control Monitor** is a computer vision–based system designed to automatically monitor and manage crowd density in public spaces such as malls, stores, and commercial buildings. Developed in response to the COVID-19 pandemic, the system enforces social distancing guidelines by **counting people in real time** and generating alerts when occupancy limits are exceeded.

This project demonstrates applied expertise in **computer vision, real-time video processing, multithreading, and intelligent surveillance systems**, making it well-suited for **AI, machine learning, computer vision, and data engineering portfolios**.

---

## Objectives

- Enforce social distancing norms using automated crowd monitoring  
- Replace manual and error-prone crowd management methods  
- Provide real-time occupancy tracking and alerts  
- Leverage existing CCTV infrastructure for cost efficiency  

---

## System Description

The system processes **live CCTV camera feeds** using computer vision algorithms to detect and count individuals entering and exiting a monitored area. When the number of people exceeds a predefined threshold, the system automatically triggers alerts to authorities or store managers, enabling immediate corrective action.

Additionally, the system records footfall data, allowing businesses to analyze customer flow patterns and optimize operational decisions.

## Project Workflow

1. **Video Stream Acquisition**  
   - Capture live video feed from CCTV cameras.

2. **People Detection & Tracking**  
   - Detect individuals using computer vision models.  
   - Track entries and exits to maintain real-time count.

3. **Occupancy Monitoring**  
   - Compare current count against predefined capacity limits.

4. **Alert Generation**  
   - Trigger alerts when occupancy thresholds are exceeded.

5. **Data Logging & Analysis**  
   - Store footfall data for trend analysis and reporting.
